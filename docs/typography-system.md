# Typography system

virtualmase uses one type family: **Instrument Sans Variable**. Its precise neo-grotesque structure supports the workshop grid, while subtle character details keep the identity independent and approachable. One family keeps every surface congruent; variable weight and width provide enough contrast for navigation, labels, body copy, and large display headings.

## Roles

| Role | Treatment |
| --- | --- |
| Display and section headings | 700 weight, tight tracking, compact line height |
| Body copy | 400 weight, open line height |
| Navigation and controls | 600–700 weight, uppercase, wider tracking |
| Technical labels and metadata | 600–700 weight, uppercase or tabular structure |

The interface does not switch to a decorative serif or coding monospace for personality. Hierarchy comes from scale, weight, spacing, case, color, and layout.

## Delivery

The variable WOFF2 is self-hosted at `assets/fonts/instrument-sans-variable.woff2`, preloaded from the page head, and served with `font-display: swap`. Arial is the only fallback. Instrument Sans is licensed under the SIL Open Font License; the license is stored alongside the font.
