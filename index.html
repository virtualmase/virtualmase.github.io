02

ROUTE METHOD

Public work needs
more than a front door.

The root directory names the distinctions that make a multi-property system legible. It does not claim that every property has the same maturity, audience, or authority.

Learning
Explains a system so a reader can build judgment.
Reference
States terms, sources, and correction pathways precisely.
Practice
Shows bounded work records without inflating them into credentials.
Participation
Exposes the source and governance constraints for responsible contribution.

OPERATING BOUNDARY

A route is not
a shortcut to trust.

Trust cannot be supplied by a logo, a design treatment, or an undifferentiated collection of pages. The public work here asks readers to inspect its sources, boundaries, and correction paths—and to distinguish a source-ready surface from a deployed one.
