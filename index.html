HOW IT WORKS

Small loops.
Visible learning.

  1. 01Notice

    Find a problem that keeps showing up.

  2. 02Make

    Write the smallest method that could help.

  3. 03Try

    Use it in a real project and keep notes.

  4. 04Open

    Publish the guide, examples, and limits.

  5. 05Revise

    Change the skill when reality proves it wrong.
