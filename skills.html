SKILLS GUIDE

Choose the method
that fits the moment.

The lifecycle skills are small, practical guides for real project work. Use them as entry points, not as a rigid process.

FAST ROUTING

Start with the pressure you feel.

Unclear ideaPrototype

Use when the main risk is uncertainty and you need a small test before committing.

Open skill ↗ Reviewed planBuilder

Use when the work is approved and needs to become tested, reviewable source.

Open skill ↗ Too much clutterSweeper

Use when old files, routes, claims, or dependencies are making maintenance harder.

Open skill ↗ Worth sharingGrower

Use when a public project needs clearer positioning, channel fit, and an honest growth loop.

Open skill ↗ Already shippedMaintainer

Use when a live project needs triage, release hygiene, checks, and ownership clarity.

Open skill ↗ Experience questionExperience Research

Use when a page, product, or journey needs sharper observation and a measurable test plan.

Open skill ↗

NOT SURE?

Use the smallest reversible skill first.

If the project still has major unknowns, start with Prototype. If the project is live and messy, start with Maintainer or Sweeper. If the work is already useful but unseen, start with Grower.
